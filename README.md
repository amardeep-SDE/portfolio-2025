## 🌟 Key Features

- 🤖 **Interactive AI Recruiter Copilot (`Gemini AI`)**
  - Integrated with Google Gemini API to answer recruiter questions in real-time.
  - Recruiter-focused prompts (salary expectations, notice period, tech stack depth, culture fit).
  - Streaming markdown responses, voice synthesis readiness, and celebratory confetti triggers.

- 💻 **Interactive Developer Terminal (`DevTerminal`)**
  - Real CLI experience with bash-style autocompletion, history navigation, and commands:
    `help`, `skills`, `projects`, `exp`, `bio`, `contact`, `hire`, `clear`, `cat resume`.

- 🎨 **Dynamic Visuals & Micro-Interactions**
  - Three.js / Vanta.js dynamic particle background with smooth responsive rendering.
  - Custom celebration effects (Rocket launch, Starlight fireworks, Confetti bursts).
  - Floating macOS-style dev window with active code tabs.
  - Interactive hover cards (e.g. Chandigarh tech hub card, experience milestone badges).

- 🌐 **Multilingual Internationalization (i18n)**
  - Seamless instant language switching (English, Hindi, German, Spanish, French).
  - Powered by `i18next` and `react-i18next`.

- ⚡ **Cutting-Edge Performance & Architecture**
  - Powered by **React 19** + **Vite 7** for lightning-fast HMR and bundle splitting.
  - Accessible, responsive, mobile-first design with smooth Framer Motion animations.
  - Dark / Light mode toggle with persistent local preferences.

- 📱 **Instant Recruiter Reach**
  - 1-Click WhatsApp direct messaging with custom prefilled recruiter greeting.
  - Direct resume download (`/amardeep_React_Fullstack.pdf`).
  - Secure contact form with instant client-side feedback.

## 🚀 Getting Started Locally

### 1. Prerequisites
- **Node.js**: `v20.x` or higher recommended
- **npm** or **yarn** / **pnpm**

### 2. Clone the Repository
```bash
git clone https://github.com/amardeep-SDE/portfolio-2025.git
cd portfolio-2025/client
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Open `.env` and add your free Google Gemini API key:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
```
> 💡 **Tip:** You can obtain a free Gemini API key from [Google AI Studio](https://aistudio.google.com/). The portfolio still runs gracefully in fallback mode if no key is provided!

### 5. Run the Local Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 6. Build for Production
```bash
npm run build
```
Preview the production build locally:
```bash
npm run preview
```

## 🔒 Security Best Practice for Production Deployments

When deploying to **Vercel** or **Netlify**:
1. Add `VITE_GEMINI_API_KEY` to your hosting provider's **Environment Variables** settings.
2. In [Google AI Studio](https://aistudio.google.com/api-keys), configure key restrictions:
   - **Application restrictions** &rarr; **Websites (HTTP referrers)**
   - Enter your domain (e.g., `https://portfolio-2025-g29b.vercel.app/*`).
3. This ensures no third party can misuse your API quota.
